Python integration · compile FSCSS

Use FSCSS from your Python project

The fscss package wraps the FSCSS compiler so you can compile strings, files, and asset directories from Python. It also includes a CLI and small Flask and Django helpers.

Python 3.8+ Node.js required Plain CSS output

01 / Install

Install the wrapper

Install the Python package in your project environment. The package vendors the FSCSS JavaScript compiler, but Node.js must be available on your PATH at runtime.

pip install fscss
node --version

For a reproducible build, pin the package version and use the same Node.js version in local development and CI.

02 / Files

Compile an FSCSS file

Use compile_file when you already have a .fscss file. The output path is created if its parent directory does not exist.

import fscss

fscss.compile_file("static/style.fscss", "static/style.css")

The function returns the compiler's combined output and raises RuntimeError when Node.js is unavailable, compilation times out, or the compiler process fails.

03 / Strings

Compile source held in memory

compile_string is useful for generated styles, tests, and small tools. Without an output path it returns the generated CSS directly.

import fscss

source = """
$accent: #8f6bff;

.card {
  color: $accent!;
}
"""

css = fscss.compile_string(source)
print(css)
04 / Assets

Compile a whole directory

compile_dir finds every .fscss file and writes a sibling .css file. Set recursive=False to scan only the top-level directory.

from fscss import compile_dir

compiled = compile_dir("static")
for source, output in compiled:
    print(f"{source} -> {output}")
05 / Web apps

Connect Flask or Django

Flask

Call init_flask after creating the app. It compiles the app's static folder and watches it automatically when Flask debug mode is enabled.

from flask import Flask
import fscss

app = Flask(__name__)
fscss.init_flask(app)

Django

Call init_django from an app startup hook or pass an explicit static directory.

import fscss

fscss.init_django("static")
06 / CLI

Use the command line

The package also exposes the same compiler through the fscss command. If you omit the output path, it writes beside the input file with a .css extension.

fscss static/style.fscss static/style.css
fscss static/style.fscss --watch
fscss --version
